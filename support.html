Get started

Caldrixa works with data you supply. Add an ABI to the local library, select it in Decode or Compare, and paste complete 0x-prefixed calldata. You can also use the built-in fictional example to try the full workflow without preparing a file.

What you can inspect

A matching function signature, its supported decoded parameter names, types and exact values, and the original calldata. Compare uses one selected ABI for both A and B.

Input formats

ABI JSON

Paste a Solidity JSON ABI array or select a JSON compiler artifact containing an abi array. Caldrixa reads function definitions for calldata decoding. Save the ABI with a name so you can select it again later.

Calldata

Paste the full hexadecimal value, including its 0x prefix and 4-byte function selector. The data must contain complete encoded arguments. Leading or trailing whitespace from a copy operation is ignored.

Common issues

“No matching function”

Check that the selected ABI belongs to the call and includes its function. The first four calldata bytes must match a selector in that ABI.

Invalid or incomplete calldata

Check the 0x prefix, hexadecimal characters, and full encoded payload. A truncated value cannot be decoded reliably.

Ambiguous or unsupported result

An ABI may contain duplicate or colliding selectors, or a type the local decoder does not support. Caldrixa shows that state instead of inventing parameter values.

Amounts look unexpectedly large

Integer values are shown as encoded. Check the token’s decimal precision separately before reading an integer as a token quantity.

Reports and sharing

After decoding or comparing, preview a report before copying, saving, or sharing it. Reports can be exported as UTF-8 text or JSON. They include the supplied calldata and available decoded values; the complete ABI is not attached by default.

A report is a record of local interpretation. It is not an on-chain verification, execution prediction, or safety assessment.

Contact support

If a result is unclear or a feature is not working, email us. Include your iOS version, what you tried, and the error shown. You may include a minimal example ABI and calldata if you are comfortable sharing them. Remove anything sensitive first.
